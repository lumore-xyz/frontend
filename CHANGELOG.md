The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

## [1.1.0] – No frontend-facing changes this release

### Changed
- **No frontend-facing changes in this release.** All v1.1.0 work landed on the backend (in-app notification system + AI match notes for community rooms + admin icon catalog), the admin web app (icon picker for dynamic options), and the mobile app (notification bell + list + screens). The legacy web frontend (`lumorefe`) was not modified in this cycle.

### Internal
- Version bumped from `0.1.0` → `1.1.0` to align with the rest of the Lumore stack. No new exports, routes, or components were added.

## [0.1.0] – Initial frontend baseline
- Initial release. Next.js public-facing web frontend. Authentication, profile browsing, and discovery flows that mirror the mobile experience for users on desktop.
